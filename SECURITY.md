# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use the repository's
**Security → Report a vulnerability** flow to open a private security advisory.

Include reproduction steps, the affected feature, expected impact, and any
suggested mitigation. This sample project is maintained on a best-effort basis,
so response times are not guaranteed.

## Dependency reports

Dependabot checks npm and GitHub Actions dependencies. A scheduled GitHub
Actions workflow also uploads the full `npm audit` JSON report and writes a
severity summary. Audit findings are reviewed before upgrades; automated
force-upgrades are not applied.
